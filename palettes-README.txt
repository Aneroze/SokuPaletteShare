Your palettes go in the PaletteShare folder of your GAME folder, not in this mod folder:

    <game folder>\PaletteShare\palettes\<character>\

That folder (one per character: reimu, udonge for Reisen, utsuho for Okuu, chirno for Cirno,
meirin for Meiling...) is created the first time you start the game with PaletteShare. In game:
Profile > Deck Construction > a character > C > "Open palette folder" opens it.

Why not here: removing the mod in SokuLauncher deletes this whole folder. The game folder's
PaletteShare folder stays, along with your palettes and their settings.

(Palettes already in a "palettes" folder here are still read, but move them over.)
